- **Metrolist** & **SimpMusic**
  - Foundational YouTube Music playback and UI paradigms in the open-source community

- **LRCLIB** ([https://lrclib.net](https://lrclib.net)) & **Better Lyrics**
  - Synchronized, time-coded and plain-text lyrics delivery API

  - InnerTube web and mobile endpoint specifications for audio extraction and query parsing
